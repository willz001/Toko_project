WAKAGO - LOCAL SERVICES DIRECTORY PROTOTYPE

Pages:
- index.html: Home page
- explore.html: Search and filter 7 sample vendors
- vendor.html: Reusable vendor profile page; each vendor has its own URL using ?id=...
- saved.html: Saved Businesses page; save/unsave vendors and revisit them later
- about.html: About page and requested footer copyright

Features:
- Search by name, service or location; filter by category and Yola area
- Vendor profile images, sample ratings, service details, WhatsApp and phone buttons
- Save Business button on each vendor profile; optional save buttons on vendor cards
- Saved businesses are stored in localStorage on the same browser/device
- Light mode is bright white; dark mode is a softer charcoal theme

Technologies: HTML5, CSS3, vanilla JavaScript and localStorage. No login or backend required for this front-end demonstration.

Preview: extract the ZIP and open index.html in a browser. Internet access is needed for remote sample photos and Google Fonts.

Important: All 7 vendor names, ratings, review counts, addresses and contact numbers are fictional sample content. Replace with verified business details before public use.
